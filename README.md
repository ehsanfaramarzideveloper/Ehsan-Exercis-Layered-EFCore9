# پروژه تمرینی معماری لایه‌ای با EF Core 9

این پروژه یک نمونه عملی برای پیاده‌سازی **معماری چندلایه (Layered Architecture)** و استفاده از جدیدترین نسخه **Entity Framework Core 9** است. هدف از این پروژه، نمایش درک عمیق از روابط دیتابیس و سازمان‌دهی کدهای دات‌نت به صورت حرفه‌ای بوده است.

## 🛠 تکنولوژی‌های استفاده شده
- **.NET 9**
- **EF Core 9** (MS SQL Server)
- **C#** (Advanced Concepts)
- **Layered Architecture** (Data Access Layer, Business Logic Layer, UI)

## 🏗 ویژگی‌های پروژه
- استفاده از **Code First** برای طراحی دیتابیس.
- پیاده‌سازی روابط پیچیده بین جداول.
- مدیریت رشته‌های اتصال (Connection Strings) و پیکربندی Context.
- سازمان‌دهی مدل‌ها و لایه‌ها جهت توسعه‌پذیری بالا.

## 🚀 نحوه اجرا
1. ابتدا دیتابیس خود را در فایل `appsettings.json` یا کلاس پیکربندی تنظیم کنید.
2. دستور `Update-Database` را در Package Manager Console اجرا کنید.
3. پروژه را Build و اجرا کنید.
